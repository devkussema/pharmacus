### 3.3 Sistema de Configuração Customizado
Foi implementada uma função `nem()` em `bootstrap/app.php` que lê configurações do arquivo `.nem_conf`:

```php
function nem($key, $default=null)
{
    $nemFile = base_path('.nem_conf');
    if (file_exists($nemFile)) {
        $nemContent = file_get_contents($nemFile);
        $nemConfig = json_decode($nemContent, true);
        
        $keys = explode('.', $key);
        $value = $nemConfig;
        
        foreach ($keys as $part) {
            if (isset($value[$part])) {
                $value = $value[$part];
            } else {
                return null;
            }
        }
        
        return $value;
    }
    
    return $default;
}
```
